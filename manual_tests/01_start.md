# 01 Start

## MT-01: Die Anwendung startet

**Voraussetzung:** `dist/index.html` ist gebaut.

**Schritte**

1. Datei `index.html` per Doppelklick öffnen.

**Erwartet**

- Kurz „Die Daten werden geöffnet …“, dann die Räder-Navigation mit den Bereichen „Erfassen“,
  „Monat“ und „Einstellungen“ und der Seite „Stempeln“.
- Nicht offensichtlich: Beim allerersten Start gibt es keine Passwortabfrage (die App-Sperre ist aus,
  die Daten sind trotzdem verschlüsselt gespeichert). Die Sperre schaltet man unter „Einstellungen“ ein.
- In der Browser-Konsole stehen keine Fehler.
